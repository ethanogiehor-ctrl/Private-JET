# User Stories & Acceptance Criteria

## Context
Our student support platform helps university students find
study partners and organize their academic goals. This section
describes what users should be able to do and how we will check
that these features work.

## Content

### User Story 1: Find Study Partners
As a  university student (especially a first year), I want to search for study partners. I am also looking for a space where i can make new friends while also having a conducive and reliable study environment. 

 I can study with people learning the same material.

Acceptance Criteria:
- The student can enter a course code, their study prefences and any other 
- The platform displays study partners matching that course.
- If there are no matches, the platform displays a clear message.

### User Story 2: Create an Academic Goal
As a university student, I want to record an academic goal
so that I can keep track of what I need to accomplish.

Acceptance Criteria:
- The student can enter a goal title and target date, and study preferences.
- The platform prevents the student from saving an empty title.
- A saved goal appears in the student's goal list.

### User Story 3: Track Goal Completion
As a university student, I want to mark a goal as complete
so that I can see my progress.

Acceptance Criteria:
- The student can mark an existing goal as complete.
- Completed goals are clearly distinguished from unfinished goals.
- The student can change a completed goal back to unfinished.
