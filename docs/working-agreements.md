PairPressure — Team Working Agreements

Team: P(rivate) JET
Project: PairPressure — Study Partner Matching App
ACTIVITY 1

1. COMMUNICATION CHANNELS
   We use our team group chat (iMessage, Discord etc.) for daily communication and GitHub Issues and Pull Requests for project discussions. Final decisions will be documented in GitHub Issues or the Wiki so everyone can access them.

2. RESPONSE TIMES
   All team members should strive to respond as early as possibble (usually during a 6 hour period). When anyone is unavailable they should let others know.

3. MEETING ETIQUETTE
   All members should be present during the meetings in order to ensure proper collaboration.

4. PULL REQUEST TONE
   PR comments should be respectful, constructive, and focused on improving the work rather than criticizing individuals. Suggestions should clearly explain what needs improvement and why.
